# Borrower Record Centre

Internal staff archive for Super Admin, Registration Officer, Approver, and Auditor.

| Role | Path |
| --- | --- |
| Super Admin | `/records` |
| Approver | `/approver/records` |
| Registration Officer | `/officer/records` |
| Auditor | `/auditor/records` |

Collectors do not receive this navigation.

## Search

Query matches borrower name, ID, phone, Ghana Card / ID number, guarantor name or phone, group name, and community.

## File view

Passport-style photograph, personal and location fields, guarantor, group/collector, audit timeline, notification deliveries, and PDF / Word / print export using the existing review-document export engine.

This is not a public borrower portal.
