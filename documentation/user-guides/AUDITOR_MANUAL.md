# WILMS Auditor Manual

**Version:** 1.7.3  
**Role:** Auditor  
**Classification:** Confidential

---

## 1. Overview

Auditors have read-only access to reports, audit logs, risk flags, and export artefacts. You cannot modify borrowers, loans, payments, or system settings.

---

## 2. Getting started

Login with auditor credentials. Dashboard shows read-only KPIs and report shortcuts.

---

## 3. Reports

Reports → Select report type. Available reports include:
- Portfolio summary
- Collection performance
- Overdue analysis
- Disbursement register
- Expense summary
- Reconciliation status
- Borrower register

Apply filters and run. Export using contextual export buttons (PDF, Excel, CSV).

---

## 4. Audit log

Audit → Filter by:
- Action type (login, approval, payment, etc.)
- Actor (user)
- Date range
- Target entity

All entries are immutable. Use for compliance verification and investigation.

---

## 5. Risk flags

Risk Flags → View all active and resolved flags. Read-only. Review approver decisions documented in audit log.

---

## 6. Executive intelligence

Executive Intelligence → View board-grade KPIs, portfolio breakdown, and forecast. Export compliance pack for external review.

---

## 7. Exports

All exports include confidentiality footer. Store exported files securely. Do not share outside authorized personnel.

**Note (v1.7.3):** Export from report pages and executive intelligence directly. Standalone Export Center removed.

---

## 8. What you cannot do

- Approve/reject loans or registrations
- Record payments or expenses
- Modify users, pools, or settings
- Delete audit log entries

---

## 9. Audit procedures

### Monthly review

1. Run portfolio summary report
2. Review reconciliation status for open items
3. Sample audit log for privileged actions
4. Verify expense approval chain (submitter ≠ approver)
5. Export compliance pack for records

### Investigation

1. Identify entity (borrower, loan, user)
2. Filter audit log by target entity
3. Cross-reference with report data
4. Document findings in external audit workbook

---

## 10. Best practices

- Export reports before external audit deadlines
- Never attempt to modify data — contact admin
- Report suspicious audit log entries to programme director
- Maintain secure storage of exported files
