# WILMS Brand System

**Version:** 1.7.3  
**Classification:** Internal

---

## 1. Brand identity

WILMS represents trust, financial integrity, and community empowerment for women's interest-free lending programmes.

---

## 2. Colour palette

### Primary

| Name | Hex | Usage |
|------|-----|-------|
| WILMS Green | `#0F6E56` | Primary brand, headers, CTAs, PDF covers |
| WILMS Green Light | `#14B88B` | Hover states, accents |
| WILMS Green Dark | `#0A5240` | Dark mode primary |

### Neutral

| Name | Hex | Usage |
|------|-----|-------|
| Text Primary | `#1A1A2E` | Body text |
| Text Secondary | `#6B7280` | Captions, metadata |
| Background | `#FFFFFF` | Page background |
| Surface | `#F9FAFB` | Cards, panels |
| Border | `#E5E7EB` | Dividers, inputs |

### Semantic

| Name | Hex | Usage |
|------|-----|-------|
| Success | `#059669` | Positive states, collected |
| Warning | `#D97706` | Pending, attention |
| Error | `#DC2626` | Errors, overdue |
| Info | `#2563EB` | Informational |

### Financial identity (v1.7.2+)

Dashboard financial surfaces use green-forward colour identity for KPI cards and hero sections.

## 4. Logo usage

- Wordmark: **WILMS** in WILMS Green (#0F6E56), bold
- Tagline: "Women's Interest-Free Loan Management System"
- Minimum clear space: height of the "W" on all sides
- Do not distort, recolour outside palette, or add effects

Logo assets: `documentation/assets/` (future placement).

---

## 5. Document templates

### PDF cover page

- Full-width green header bar (#0F6E56, 50mm height)
- White WILMS wordmark centred
- Tagline below wordmark
- Document title and version below header
- Confidentiality footer on every page

### DOCX cover

- Centred WILMS wordmark in #0F6E56
- Tagline in 11pt
- Document title in 12pt italic
- Section headings in Heading 1 style

Generated by `scripts/generate-documentation-suite.mjs`.

---

## 6. Export branding

All PDF exports from the application and documentation generator include:
- Green cover/header bar
- WILMS wordmark
- Version identifier
- Confidentiality footer: "CONFIDENTIAL — For authorized WILMS personnel, executive review, procurement, and official record keeping only."

---

## 7. UI component patterns

- Buttons: primary green, secondary outline, destructive red
- Cards: white surface with subtle border, rounded corners
- Badges: semantic colours for status
- Modals: centred overlay with focus trap
- Toast: bottom-right, auto-dismiss

Design system primitives in `apps/frontend/src/components/ui/`.

---

## 8. Iconography

Sidebar navigation uses distinct icons per section (v1.7.2+). Lucide icon set. Consistent 20px size in sidebar, 16px inline.
