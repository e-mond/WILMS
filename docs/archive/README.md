# Documentation Archive

This directory stores **historical** WILMS documentation: phase validation notes, certification evidence packs, and superseded root reports.

These files are retained for audit and traceability. They are **not** the source of truth for the current system.

For current documentation, start at [`docs/README.md`](../README.md) and the root [`README.md`](../../README.md).

| Subfolder | Contents |
|---|---|
| `root-reports/` | Former repository-root one-off reports (pre–v1.5 consolidation) |
| `page-validation-v14/` | Phase page-validation notes |
| `page-validation-legacy/` | Older page-validation archives |
| `releases/` | Historical release write-ups |
| `certification/` (sibling under `docs/certification`) | Versioned certification packs |
| `v1.0.0-rc*`, `v1.1.1-release`, … | Version-scoped historical packs |

Do not update archived documents to match current behavior; create new docs under `docs/` instead.
