# Navigation (v1.6.1)

## Shell structure

- `AppNavbar` — sticky, blurred, elevated on scroll
- `AppSidebar` / `ShellNavigation` — grouped, collapsible, role-aware
- Mobile drawer forces expanded labels

## Shortcuts

| Shortcut | Action |
|----------|--------|
| Ctrl/Cmd+K | Open global search |

## Persistence

| Key | Purpose |
|-----|---------|
| `wilms.shell.nav-groups` | Collapsed nav group map |
| shell layout store | Desktop sidebar collapsed |
| `wilms.global-search.recent` | Recent search queries |
